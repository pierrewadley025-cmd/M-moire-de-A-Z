# M-moire-de-A-Z
Cette plateforme vous accompagne dans la réalisation de votre mémoire, de l’idée initiale à la soutenance. Vous y apprendrez à choisir et construire votre sujet, formuler la problématique, les hypothèses et les variables, élaborer le cadre théorique, collecter et analyser les données, rédiger, citer vos sources et éviter le plagiat.
